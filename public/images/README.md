# Website Images

Place website images in this folder. Next.js serves these files from the site root.

For example:

- File: `public/images/school-logo.png`
- Website path: `/images/school-logo.png`
- React/Next.js usage: `src="/images/school-logo.png"`

Use lowercase, descriptive filenames with hyphens, such as `diocese-of-baguio-logo.png`.
